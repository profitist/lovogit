# Proposal

## Why

Инвентарь уже определяет подтверждённую файлами текущую версию, а сбор материалов принимает готовую пару current/target. Между ними отсутствует выбор target: для MVP согласована единая политика — последняя стабильная версия PyPI, без ограничения диапазоном проекта, с исключением prerelease, dev и yanked.

## What Changes

- Добавить отдельную операцию выбора обновления для одной декларации инвентаря с известной registry-версией.
- Сравнивать релизы по PEP 440 и выбирать максимальный стабильный неотозванный релиз строго выше текущей версии. Post-релизы входят в стабильные; local-варианты не выбираются как публичный target.
- Не фильтровать target по specifier, constraints, requires-python, платформе, extras или marker. Сохранять исходную декларацию и ограничения для последующего анализа.
- Возвращать явные результаты `selected`, `no_update`, `skipped`; только selected содержит `UpdateSourceRequest`. Не запускать анализ для неизвестной, конфликтующей или неподдержанной текущей версии.
- Проверять yanked и идентичность через metadata явно заданного релиза, ограничивать число проверок и общее время; ошибки PyPI и исчерпание бюджета не выдавать за отсутствие обновлений.
- Добавить документированный путь от реального инвентаря до запроса сбора changelog и автономные тесты без платной модели и сети.

## Capabilities

### New Capabilities

- `dependency-update-selection`: выбор целевой версии обновления по политике последнего стабильного релиза и формирование пары current/target с происхождением и явным результатом отсутствия кандидата.

### Modified Capabilities

Нет. Инвентарь остаётся статическим; `update-source-collection` продолжает читать только явно переданную пару, не выбирая версии самостоятельно.

## Impact

- Новый обычный модуль `src/lovogit/app/update_selection.py` с функцией выбора и небольшими DTO результата; без нового сервиса, фабрик стратегий или иерархии классов.
- Переиспользуются `DependencyDeclarationDTO`, `PyPiProvider.get_package`, `get_package_info`, `UpdateSourceRequest` и существующая зависимость `packaging`.
- Дополняются `docs/dependencies.md`, `docs/pypi.md` и правило выбора target в `docs/mvp.md`; добавляются профильные и интеграционные тесты.
- Схемы PyPI, существующие DTO провайдера, БД, бот, расписание, sandbox, comparer и runtime-конфигурация модели не изменяются. Выбор target не означает разрешимость установки или совместимость обновления.
