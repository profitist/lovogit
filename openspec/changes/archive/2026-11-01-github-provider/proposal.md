# Proposal

## Why

Для оценки влияния обновления библиотеки нужен воспроизводимый снимок основной ветки GitHub-проекта. Сейчас GitHub-провайдер пуст, а существующая абстракция смешивает получение исходников с разбором зависимостей, поэтому её нельзя удобно использовать как основу будущих тулов.

## What Changes

- Добавить асинхронный GitHub-провайдер: нормализация `github_url`, чтение метаданных, разрешение default branch в commit SHA и получение архива этой ревизии.
- Использовать один настроенный токен экземпляра для любых репозиториев: доступ определяется GitHub, отдельного режима public/private нет.
- Предоставлять управляемый локальный снимок с метаданными репозитория, веткой и SHA; очищать временные данные после использования и при сбоях.
- Отделить получение кода от извлечения зависимостей; согласовать существующий `RepoService` с новым контрактом без выдуманного пустого инвентаря.
- Добавить независимые настройки GitHub, классификацию ошибок и автономные тесты HTTP/архивов.
- Не включать регистрацию списка проектов в БД/конфигурации, парсеры зависимостей, историю Git, LLM, тулы, агентский цикл, расписание и изменения интерфейсов. Провайдер получает URL от вызывающего кода; подключение проектов будет следующим изменением.

## Capabilities

### New Capabilities
- `github-source-snapshot`: получение и освобождение снимка default branch GitHub-репозитория по неизменяемому SHA с единым правилом доступа и явными ошибками.

### Modified Capabilities

Нет. История мониторинга и поведение `/status` не меняются.

## Impact

- `src/lovogit/app/providers/`: контракты, GitHub-реализация, ошибки и экспорты.
- `src/lovogit/app/services/repo.py`: устранение зависимости подключения кода от ещё не реализованного `get_deps`.
- `src/lovogit/cfg/`: отдельные настройки без требования Telegram/LLM; документация в `docs/dev-docs.md`.
- `pyproject.toml` и `uv.lock`: прямая зависимость на асинхронный HTTP-клиент `httpx`.
- Новые тесты без реального GitHub и секретов. Миграции БД и изменения действующих спецификаций не требуются.
