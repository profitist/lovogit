# Spec Delta

## MODIFIED Requirements

### Requirement: Пустые и неизвестные результаты
При отсутствии успешного снимка команда MUST сообщать «Оценки обновлений пока нет». При наличии снимка без выбранных статусов MUST сообщать «По этому снимку зависимостей, требующих внимания, нет». При отсутствии проектов MUST сообщать «Проекты не настроены» и предлагать `/add_repo <github-url>` для подключения репозитория. Состояния MUST показываться отдельно по каждому проекту.

#### Scenario: Нет успешной проверки
- **WHEN** запусков нет либо существуют только выполняющиеся или неудачные запуски
- **THEN** ответ не утверждает отсутствие проблем и сообщает об отсутствии оценок с состоянием последнего запуска, если он есть

#### Scenario: Пустой либо спокойный снимок
- **WHEN** успешный снимок пуст либо содержит только `waiting`, `low`, `current`
- **THEN** ответ сообщает об отсутствии требующих внимания зависимостей именно по этому снимку

#### Scenario: Смешанное состояние проектов
- **WHEN** один проект без оценок, у другого есть выбранные зависимости, а у третьего их нет
- **THEN** ответ содержит все три проекта с соответствующими состояниями

#### Scenario: Нет проектов
- **WHEN** неудалённые проекты отсутствуют
- **THEN** ответ сообщает об отсутствии настроенных проектов и предлагает `/add_repo <github-url>`
