# SessionFlow — бэклог

Что запланировано после MVP. Состав первой версии — в [mvp.md](mvp.md).

## Версия 0.2

- Более точное определение ожидания ввода и подтверждения.
- Git-интеграция.
- Сравнение файловых изменений с контекстом задачи.
- Поиск и фильтрация по содержанию сессий.

## Версия 0.3

- Обнаружение потенциально дублирующихся задач.
- Поиск конфликтов между сессиями, работающими в одном репозитории.
- История прогресса и восстановление контекста.
- Уведомления о важных событиях.

## Версия 0.4

- MCP-сервер SessionFlow.
- Запросы к доске из Claude Code.
- Создание и обновление задач через MCP.
- Управление сессиями через поддерживаемые и документированные механизмы.

## Версия 1.0

- Расширенная аналитика работы нескольких агентов.
- Поддержка дополнительных coding-агентов через отдельные адаптеры.
- Планирование и координация задач.
- Опциональная оркестрация через LangGraph с контролем пользователя.

## Явно исключено из MVP

Эти пункты не входят в первую версию; версия для них пока не назначена.

- Автоматическое изменение кода.
- Автоматическое выполнение терминальных команд.
- Полноценная поддержка других coding-агентов (частично — в 1.0).
- Автоматическое распределение задач между сессиями.
- Сложная многоагентная система.
- Облачная синхронизация и командная работа.
