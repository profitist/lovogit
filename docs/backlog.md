# LovoGit — бэклог

Что запланировано после MVP. Состав первой версии — в [mvp.md](mvp.md).

В дальнейшем LovoGit может превратиться в систему непрерывного контроля совместимости зависимостей. Возможности ниже должны появляться по мере подтверждения востребованности продукта и качества его анализа.

## Направления развития

- Поддержка дополнительных языков программирования и пакетных менеджеров.
- Интеграция с GitHub, другими платформами размещения кода и системами контроля версий.
- Анализ совместимости с учётом тестов проекта.
- Отчёты по проектам и для команд.
- Рекомендации по миграции между версиями и по подготовке изменений.
- Подготовка pull request с предложенными исправлениями.
- Расширенный мониторинг безопасности и устаревших зависимостей.
- Управление уведомлениями из бота: отложить уведомления по зависимости или версии (`/mute`), игнорировать мажорные обновления, выбрать минимальный уровень риска для уведомлений.

## Явно исключено из MVP

- Полноценная SaaS-платформа.
- Сложный веб-интерфейс.
- Автоматическое изменение кода (частично — через pull request с исправлениями, см. выше).
